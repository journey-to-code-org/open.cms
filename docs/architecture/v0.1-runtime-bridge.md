# 0.1.x runtime bridge

The 0.1.x site packages are migration fixtures. The existing app still reads legacy root inputs:

```text
CURRENT LEGACY RUNTIME INPUTS
content/ · src/model/ · public/ · index.html · explore.html
scripts/content-site.js · vite.config.mjs
                    ↓ planned 0.2.x extraction
SITE-PACKAGE RUNTIME
sites/<site>/
```

`sites/garrett-county/` currently copies migration data, while root Garrett content, models, assets, and HTML continue to power parts of the application. Contributors should not assume a change to the package fixture changes the live build.

The 0.2.x runtime extraction will make a selected package the authoritative source for site data and generated output. After that boundary is in place, the real Garrett package can move to a private repository without requiring Garrett-specific engine code.

The root `docs/README.md` remains a Garrett-specific operating and data guide for the transitional app. Legacy `chingu-mapbox` cache-name prefixes in the service-worker cleanup code are intentionally retained to remove caches created by older installs; they are not repository or package identifiers.
