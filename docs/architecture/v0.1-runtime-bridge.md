# Historical runtime bridge note (0.1.x)

This note records the 0.1.x transition before site packages became executable. Its statements about the current runtime were accurate for 0.1.1 and are retained for release history only.

At 0.1.1, the site package fixtures coexisted with root Garrett-derived content, model data, public assets, and static HTML. Package validation existed, but the live build did not yet accept a selected site.

Version 0.2.0 completes that bridge: the selected package now supplies validated runtime data and static output. See the [package-driven runtime architecture](v0.2-package-runtime.md) and the [updated extraction audit](site-extraction-audit.md).
